# Code Review Prompt

You are reviewing code for Vayren Core.

1. Check deprecations: does this follow the domain conventions?
2. Check imports: are they from the right places?
3. Check types: are type hints complete?
4. Check tests: are there tests for new code?
5. Check docs: are READMEs updated for public API changes?
6. Run `make check` before approving.
