# knowledge/patterns/ — Patterns

## What Are Patterns?

**Patterns** are reusable templates and conventions that make the repository consistent. They are the "standard operating procedures" of the codebase.

---

## Why This Exists

When every part of the system follows the same pattern, navigating the codebase becomes intuitive. You know what to expect in any department because the structure is always the same.

Patterns documented here:
- How to structure a new department
- How to define events
- How to set up experiments
