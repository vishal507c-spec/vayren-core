Design notes — 01 Define

Every decision below is a deliberate fix for a problem in the previous draft. This sheet is the spec; the page is the proof.

1  What changed and why

WasNowReason
Long / Short / Compare in one segmented groupDirection (Long/Short) + a separate Mode group (Single / Compare)Compare is a mode, not a direction. Mixing them made the third option read as "compare the direction", which is meaningless. Splitting gives each control one job and lets Compare expand a second slot (peer object).
List of 4 items, no contextEach row carries state, params-set, last run, best metric + Recent group + sortYou should be able to pick the right object without opening every row. The list is now a decision surface, not a name list.
Search box shown at n=4Search always present but scoped to name + tags + metrics; empty & no-result states designedConsistent control position beats conditional chrome. It is now predictable and actually returns useful hits.
Kebab with unknown contentsReal menu, destructive item separated by a rule and behind an inline confirmDestructive action must never be one unguarded click away.
Dead space under DirectionReadiness block + explicit "what happens next" line + Continue CTAThe bottom of the pane now tells you what you just configured and what you get for it.
Jargon stepper, no state6 steps with done / active / upcoming, one-line purpose each, keyboard operable"READ / INVESTIGATE / MODIFY" means nothing on first run. Purpose lines make the workflow self-teaching.

2  Tokens

Space — 4pt scale: 4 8 12 16 20 24 32 40 48. Pane padding 24, card padding 16, gap between fields 24.

Radius — 6 inputs/chips, 10 cards & menus, 14 panels, 999 pills.

Type — 11/12/13/14/16/20. Eyebrow + badge + meta use 10–11 with .6–.8px tracking and 650–700 weight. Numbers and metrics are monospace so columns align.

Elevation — two levels only: shadow-1 for resting cards, shadow-2 for overlays (listbox, menu, sheet).

Colour roles — brand teal = selection & progress. Semantic hues never carry meaning alone; each is paired with an icon and a text label.

3  Contrast targets

  • Body text ≥ 4.5:1 against its own surface. Draft's --warn on its 10% tint fails on light — light theme uses #b45309 for that reason.
  • Ink-3 is reserved for hints, meta and inactive step labels. Never for a value the user must read.
  • Focus ring is 2px solid at 2px offset on a separate --focus hue so it never reads as selection.

6  Rules

  • One control = one job. If a second meaning is needed, it becomes a second group — never a third option in the same group.
  • Selection is always shown three ways: border, tint, and text/icon. Colour alone is never the signal.
  • Nothing destructive is a single click, and nothing irreversible hides behind a hover.
  • Every control states its consequence in words somewhere on screen (hint, readiness, or next-step line).
  • Empty state is always instructional + one primary action, never a bare message.
  • Motion is ≤260ms, eased, and fully disabled under prefers-reduced-motion.
  • Dark and light are both first-class; no hard-coded hex outside the token block.
