# research/models/rl/ — Reinforcement Learning Models

## What Is RL?

**Reinforcement Learning (RL)** trains an agent to make sequential decisions by rewarding desired outcomes. In trading, RL is used for:

- **Trade execution** — when to slice orders, how to minimize slippage
- **Portfolio rebalancing** — dynamic allocation decisions
- **Market making** — bid/ask spread management
