# research/evaluation/ — Evaluation

## What Is Evaluation?

**Evaluation** is the process of measuring how well a strategy or model performs. It answers: "Does this work?"

---

## What Is Inside

| Component | Purpose |
|---|---|
| `BacktestEvaluator` | Runs strategies against historical data, computes performance metrics |
| `WalkForwardValidator` | Tests strategy robustness across multiple time windows |
| `MetricsCollector` | Records evaluation metrics for comparison and tracking |
