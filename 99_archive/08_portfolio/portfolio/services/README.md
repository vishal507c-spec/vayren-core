# portfolio/services/ — Portfolio Services

## What Is Inside

| Service | Responsibility |
|---|---|
| `PortfolioConstructor` | Builds and initializes a portfolio from config |
| `PositionTracker` | Tracks all positions in real-time, updates on fills |
| `PnLCalculator` | Computes daily, cumulative, and since-inception P&L |
| `AllocationOptimizer` | Determines optimal allocations (mean-variance, risk-parity, equal-weight) |
