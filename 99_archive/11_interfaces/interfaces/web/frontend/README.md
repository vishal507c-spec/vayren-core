# interfaces/web/frontend/ — Web Dashboard Frontend

## What Is Inside

| Component | Technology | Purpose |
|---|---|---|
| `src/` | React + TypeScript | Dashboard UI components and pages |
| `public/` | HTML + assets | Static assets and entry point |

---

## Dashboard Pages

| Route | Content |
|---|---|
| `/` | Portfolio overview (total value, P&L, open positions) |
| `/strategies` | Strategy status and performance |
| `/trades` | Trade log and order history |
| `/risk` | Risk limits, current usage, alerts |
| `/research` | Model registry, experiment results |
