## R1 FIX SHIPPED — full suite no longer hangs

Root cause was NOT GC absence alone: each `Bootstrap` leaked, but the leak was
held by **Bootstrap's own strong refs**, which GC absence prevented from ever being reclaimed.

### Root cause (proven with probes)
- Threads: each `Bootstrap` left 3 QThreads (2 running). `BrokerManager._Worker` + `data_worker` + `backtest_worker`.
- Widgets: each `Bootstrap` left **3 parentless top-level QWidgets**:
  `StrategyControlPanel`, `StrategyListPanel` (both `05_strategy/strategy/ui/`) and
  `PerformancePanel` (`06_backtest/backtest/ui/`). All three are constructed with **`parent=None`**,
  never added to a layout, held only by `self._lab_control`/`self._lab_list`/`self._performance_panel`
  AND by the `Registry` services (`lab_control_panel`, `lab_strategy_list`, `lab_performance_panel`).
  Plus `ChartWindow` had **no `WA_DeleteOnClose` and no `closeEvent`** → `close()` only hid it,
  so its ~1,150-widget tree lived forever.

### Three edits
1. `00_app/app/bootstrap/bootstrap.py`
   - Added **`Bootstrap.stop()`** (previously nonexistent — Bootstrap could start but never stop).
     Shuts down `data_worker`/`backtest_worker`/`broker_manager.stop_worker()`, closes the chart
     window, `self._bus.clear()`, then `_release_widget_references()` + flush `DeferredDelete`.
   - Added `_release_widget_references()` — `setParent(None)` + `deleteLater()` on every widget held
     in the services registry and on `self._*` attrs, then `setattr(self, attr, None)`.
   - Added `_drop_gui_service_entries()` — `Registry` has **no `clear()`** and rejects duplicate
     `register()`, so it pops widget entries out of `Registry._items` in place.
   - Import change: `PySide6.QtCore` now also imports `QEvent`.
   - NOTE: `_consider(value: Any)` must be typed `Any`, not `object` — pyright will not narrow
     `object`→`QWidget` via `isinstance` and reports `setParent`/`deleteLater` as unknown attrs.
2. `04_chart/chart/windows/chart_window.py` — added `closeEvent(self, event: QCloseEvent)` that
   calls `super().closeEvent(event)` then `self.deleteLater()`. Import `QCloseEvent` from QtGui.
3. `00_app/app/tests/conftest.py` — teardown calls `Bootstrap.stop()` first; GC sweep kept only
   as a safety net for non-Bootstrap threads. Use `contextlib.suppress` not `try/except/pass` (SIM105).

### Gotchas for future work
- **`shiboken6.isValid(obj)` is mandatory** when walking `gc.get_objects()` for QWidgets — Python
  wrappers outlive their C++ objects and `.isWindow()`/attribute access raises `RuntimeError`.
- `Registry` (`01_core/core/registry/registry.py`) has no `clear()`; use `._items` directly.
- pyright MUST be run as bare `pyright` from repo root (it needs `[tool.pyright].extraPaths`).
  Running it on individual files produces hundreds of bogus `reportMissingImports`.
